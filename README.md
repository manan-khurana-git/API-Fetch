# Data Fetch Project

## 📌 Project Overview

This project fetches post data from the **DummyJSON API** and displays posts in responsive cards using **HTML, CSS, and JavaScript**.

## 🚀 Features

* Fetches data using the Fetch API
* Dynamically displays posts
* Responsive grid layout
* Hover effects on cards
* Clean and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* DummyJSON API

## 🌐 API Used

https://dummyjson.com/posts

## 📂 Project Structure

```text
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 📸 Output

The application displays:

* Post Title
* Post Description
* Number of Views
